Linux 网卡驱动安装

网卡安装教程

如果你已经是国内源请直接跳到第三步安装内核头，但是记得更新列表与软件

1. 改国内源

只是为了提高下载速度哈，再此提醒一下：

而且/etc/apt/sources.list里面只能启用一个源，同时写进去多个源，每个软件源镜像站同步时间不一样，有的镜像站里同一个时间有些软件包是新的，有的是旧的，你这样添加多个源进去如果更新，软件源镜像站之前同步时间不一样包会冲突（大佬原话）

1vim /etc/apt/sources.list	#编辑kali源列表文件
2
3#按i转到编辑模式后，将以下信息替换掉原本内容，按Esc后输入:wq保存并推出
4
5#阿里云
6deb http://mirrors.aliyun.com/kali kali-rolling main non-free contrib
7deb-src http://mirrors.aliyun.com/kali kali-rolling main non-free contrib

2. 更新软件列表与软件

只更新索引，不碰已安装的包

1apt-get update	#更新软件列表

根据索引，升级已安装的包到最新版：【注意】耗时长

1apt-get upgrade	#更新软件

3. 安装Linux内核头

内核头：这个东西定义了内核组件之间的接口也定义了内核和用户空间之间的接口，说人话就是安装或编译一些跟系统有关的应用要重新编译系统，所以必须安装内核头

1apt install linux-headers-$(uname -r)	#安装与自己相对应的内核头

假如安装内核头文件报了这样一个错误（反正我报了）：

升级内核：

1sudo apt update
2sudo apt install linux-image-amd64 linux-headers-amd64

重启之后

1uname -r	#显示操作系统的发行版号
2
3# 重新安装内核头
4apt install linux-headers-$(uname -r)

检查确认内核和头文件是否一致：

1uname -r
2dpkg -l | grep linux-headers

4. 安装驱动

现在插上你的无线网卡。

1. 先确认硬件是否被识别

1# 查看所有 USB 设备
2lsusb
3
4# 查看 PCI 设备（内置网卡）
5lspci | grep -i net
6
7# 查看网络接口（不管有没有 wlan0）
8ip link show
9
10# 查看无线设备
11iw dev

查看当前驱动

1sudo ethtool -i wlan0

2. 如果 lsusb 能看到无线网卡

例如：

1└─$ lsusb
2Bus 001 Device 001: ID 1d6b:0002 Linux Foundation 2.0 root hub
3Bus 001 Device 003: ID 0bda:b711 Realtek Semiconductor Corp. RTL8188GU 802.11n WLAN Adapter (After Modeswitch)
4Bus 002 Device 001: ID 1d6b:0001 Linux Foundation 1.1 root hub
5Bus 002 Device 002: ID 0e0f:0003 VMware, Inc. Virtual Mouse
6Bus 002 Device 003: ID 0e0f:0002 VMware, Inc. Virtual USB Hub

可以看到第二行，你的 RTL8188GU USB WiFi 网卡已经成功直通到虚拟机了。

3. 安装网卡驱动

在库中搜索看有没有网卡的驱动

1apt search rtl8188gu

如果没有，那么就需要从源码编译。

  • 安装编译依赖
1sudo apt install build-essential dkms git

找一个位置下载驱动

1mkdir -p temp  # 新建一个文件夹(有就不用新建)
2cd temp

下载驱动源码 RTL8188GU 常用的是 rtl8188gu 或 rtl8188eus 驱动项目。最活跃的是这个：

1git clone https://github.com/McMCCRU/rtl8188gu.git
2cd rtl8188gu

如果上面的仓库不可用，试试开源项目（但是比较老）

1git clone https://github.com/lwfinger/rtl8xxxu.git
2
3cd rtl8xxxu
4
5make
6sudo make install
7sudo modprobe rtl8xxxu

编译驱动

make 是一个构建工具，用于自动化编译程序。

1make			# 编译驱动，生成 8188gu.ko 文件
2sudo make install  # 把编译好的模块安装到系统目录

这个命令是加载编译好的驱动模块到内核中。

1sudo modprobe rtl8188fu

如果 sudo make install 不行

手动安装

编译好的模块在当前目录，直接手动复制：

1cd ~/temp/rtl8188gu
2
3sudo cp rtl8188gu.ko /lib/modules/$(uname -r)/kernel/drivers/net/wireless/
4
5sudo depmod -a
6
7sudo modprobe rtl8188gu

使用网卡上网（连接WiFi）

恢复 Managed 模式

1sudo ip link set wlan0 down
2sudo iw dev wlan0 set type managed
3sudo ip link set wlan0 up

连接 WiFi

方法 1：用 NetworkManager（图形界面）

如果你用的是 Kali 桌面版，点击右上角网络图标，选择 WiFi 连接即可。

方法 2：命令行

启动 NetworkManager：

1sudo systemctl start NetworkManager

连接WiFi

1# 扫描周围 WiFi
2sudo nmcli dev wifi list
3
4# 连接（替换 SSID 和密码）
5sudo nmcli dev wifi connect "你的WiFi名称" password "你的密码"

验证连接

1iwconfig
2ping -c 4 8.8.8.8

先恢复 Managed 模式，然后告诉我你想用哪种方式连接。

✨其他技巧

重新加载 USB 设备

1sudo modprobe -r rtl88xxau 2>/dev/null; sudo modprobe rtl88xxau

查看当前驱动

1sudo ethtool -i wlan0

替换驱动

1sudo modprobe -r rtl8xxxu
2sudo modprobe rtl8188fu

undo tx-power undo tx-power 命令用来恢复AP内置蓝牙模块的发射功率为缺省值。 缺省情况下，AP内置蓝牙模块的发射功率为0dBm。 AP内置蓝牙模块的发射功率。 枚举值类型。 可取值为：-21、-18、-15、-12、-9、-6、-3、0、1、2、3、4、5，单位为dBm。 用户可以执行该命令修改AP内置蓝牙模块的发射功率。

1sudo ip link set wlan0 down
2sudo ip link set wlan0 up
